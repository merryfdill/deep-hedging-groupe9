# Sources de données – Deep Hedging

## Type de données
Les données seront générées par simulation informatique.

## Méthode
Utilisation du modèle GBM (Geometric Brownian Motion) pour simuler les trajectoires des prix d'un actif financier.

## Objectif
Obtenir plusieurs scénarios d'évolution des prix afin de tester et comparer les stratégies de couverture.

## Outils
- Python
- NumPy
- Pandas
- Matplotlib
