# Fiche de lecture – Deep Hedging

## 1. Sujet du projet
Étude et comparaison des stratégies de couverture financière.

## 2. Objectif
Comparer trois méthodes :
- Sans couverture
- Couverture Delta (Black-Scholes)
- Deep Hedging avec un réseau de neurones

## 3. Technologies utilisées
- Python
- NumPy et Pandas
- PyTorch
- Odoo 17
- PostgreSQL
- Docker

## 4. Objectif final
Développer une solution permettant de simuler les stratégies de couverture et de comparer leurs performances.
